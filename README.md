# My Songbook

Προσωπικό τραγουδολόγιο για κιθάρα. Ανοίγει στο **https://basile1988.github.io/my-songbook/**, σε κινητό, tablet και laptop, και δουλεύει και χωρίς internet.

## Πώς δουλεύει

- **Η εφαρμογή** είναι αυτό το repo (`my-songbook`, δημόσιο). Το GitHub Pages τη σερβίρει.
- **Τα τραγούδια** είναι στο ιδιωτικό repo `my-songbook-data`, ένα αρχείο JSON ανά τραγούδι ή λίστα. Κάθε αποθήκευση είναι ένα commit, οπότε όλο το ιστορικό μένει στο git.
- **Κάθε συσκευή** κρατά πλήρες αντίγραφο. Χωρίς σύνδεση ανοίγει και δουλεύει κανονικά, και οι αλλαγές ανεβαίνουν όταν ξαναβρεί internet.
- Το στήσιμο (repos, token, σύνδεση συσκευών) περιγράφεται στο [GITHUB.md](GITHUB.md).

## Αρχεία

- `index.html`: όλη η εφαρμογή
- `sw.js`: κρατά την εφαρμογή στη συσκευή για να ανοίγει χωρίς internet
- `manifest.webmanifest`, `icons/`: όνομα και εικονίδιο για την αρχική οθόνη

## Δομή δεδομένων (στο `my-songbook-data`)

- `songs/<id>.json`: τίτλος, καλλιτέχνης, δημιουργοί (`credits`), τόνος, είδη, ετικέτες, ρυθμός, μέτρο, κάπο, σημειώσεις, αγαπημένο, `lines`
  - `lines`: `{k:'l', s:[[ακόρντο, κείμενο], …], r:επανάληψη}` · `{k:'h', t:ενότητα}` · `{k:'b'}` κενή · `{k:'n', t:σημείωση}`
  - Κάθε ακόρντο είναι δεμένο στο κομμάτι στίχου που ξεκινά από κάτω του.
- `collections/<id>.json`: όνομα, `ordered`, `mode` (`full` | `cue`), `parent`, `notes`, `items` με τη σειρά τους:
  - `{i, s:songId, key?, note?}`: τραγούδι σε αυτή τη θέση, με δικό της τόνο και σημείωση. Το ίδιο τραγούδι μπορεί να υπάρχει πολλές φορές.
  - `{i, sec, sub?}`: ενότητα/πακέτο (π.χ. «Ρούμπες · 2ο πακέτο»). Τα τραγούδια από κάτω της ανήκουν σε αυτή.
  - Παλιές λίστες με σκέτα id τραγουδιών διαβάζονται αυτόματα στη νέα μορφή.
- Προηγούμενες εκδόσεις: το ιστορικό του git για κάθε αρχείο.
