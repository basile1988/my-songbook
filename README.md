# My Songbook

Προσωπικό τραγουδολόγιο για κιθάρα, με τη βάση μέσα σε αυτόν τον φάκελο.

## Πώς ανοίγει

1. Διπλό κλικ στο **Start My Songbook.bat**.
   Ανοίγει ένα μαύρο παράθυρο (ο server) και μετά η εφαρμογή στον browser.
2. Άφησε το μαύρο παράθυρο ανοιχτό όσο τη χρησιμοποιείς. Κλείνοντάς το, σταματάει.

Την πρώτη φορά τα Windows μπορεί να ρωτήσουν για το Τείχος προστασίας (Firewall).
Επίλεξε **Ιδιωτικά δίκτυα** για να μπορούν να μπαίνουν το κινητό και το tablet.

## Από κινητό ή tablet

Στο ίδιο Wi-Fi με το laptop, άνοιξε τη διεύθυνση που γράφει το μαύρο παράθυρο, π.χ. `http://192.168.1.23:8765`.
Τη βλέπεις και μέσα στην εφαρμογή, κάτω αριστερά, όταν την ανοίγεις από το laptop.
Μπορείς να την προσθέσεις στην αρχική οθόνη του tablet από το μενού του browser.

- Οι αλλαγές από οποιαδήποτε συσκευή φτάνουν στις άλλες μέσα σε λίγα δευτερόλεπτα.
- Αν χαθεί η σύνδεση, η σελίδα που είναι ήδη ανοιχτή συνεχίζει να δουλεύει. Οι αλλαγές περιμένουν και στέλνονται μόλις ξαναβρεί το laptop.
- Για να ανοίξει η εφαρμογή από την αρχή, πρέπει να τρέχει ο server στο laptop. Σε live χωρίς το laptop, άνοιξε το setlist στο tablet πριν φύγεις από το σπίτι και μην κλείσεις την καρτέλα.

## Αρχεία

- `index.html`: η εφαρμογή
- `server.py`: ο τοπικός server (Python, χωρίς εγκαταστάσεις)
- `songbook.db`: **η βάση με τα τραγούδια σου** (δημιουργείται στην πρώτη εκκίνηση)
- `backups/`: αυτόματο αντίγραφο της βάσης κάθε μέρα (κρατάει τα 30 τελευταία)
- `Start My Songbook.bat`: εκκίνηση με διπλό κλικ

Για να μεταφέρεις τη βιβλιοθήκη σε άλλο υπολογιστή, αντίγραψε όλο τον φάκελο.
Εναλλακτικά, πάτα «Backup» μέσα στην εφαρμογή για αρχείο .json.

## Δομή δεδομένων

- `songs`: τίτλος, καλλιτέχνης, δημιουργοί (`credits`), τόνος, είδη, ετικέτες, ρυθμός, μέτρο, κάπο, σημειώσεις, αγαπημένο, `lines`
  - `lines`: `{k:'l', s:[[ακόρντο, κείμενο], …], r:επανάληψη}` · `{k:'h', t:ενότητα}` · `{k:'b'}` κενή · `{k:'n', t:σημείωση}`
  - Κάθε ακόρντο είναι δεμένο στο κομμάτι στίχου που ξεκινά από κάτω του.
- `collections`: όνομα, `ordered`, `mode` (`full` | `cue`), `parent`, `notes`, `items` με τη σειρά τους:
  - `{i, s:songId, key?, note?}`: τραγούδι σε αυτή τη θέση, με δικό της τόνο και σημείωση. Το ίδιο τραγούδι μπορεί να υπάρχει πολλές φορές.
  - `{i, sec, sub?}`: ενότητα/πακέτο (π.χ. «Ρούμπες · 2ο πακέτο»). Τα τραγούδια από κάτω της ανήκουν σε αυτή.
  - Παλιές λίστες με σκέτα id τραγουδιών διαβάζονται αυτόματα στη νέα μορφή.
- `versions`: προηγούμενες μορφές κάθε τραγουδιού (έως 20)

Όλη η επικοινωνία με την αποθήκευση γίνεται στο αντικείμενο `Store` του `index.html`.
Για μεταφορά σε server στο internet αλλάζει μόνο αυτό.
